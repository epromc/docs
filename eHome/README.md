{% hint style="success" %}
**eHome** is an enterprise-grade, bed-themed home management plugin crafted for Minecraft 1.21+ servers. Designed with **Folia regional multi-threading**, modern **Unicode Small Caps typography**, matrix GUI pagination, and deep integrations with Web Maps, Protection plugins, and Bedrock (Floodgate), eHome delivers an unparalleled player experience with zero server lag.
{% endhint %}

---

## 🚀 Key Highlights

* **Native Folia & Paper Engine:** Complete support for Folia region schedulers and asynchronous thread isolation without main-thread blocking.
* **Bed-Themed Matrix GUI:** Interactive pattern-based chest menu (`/homes`) featuring 16 color choices, pinned favorites, and pagination.
* **Geyser & Floodgate Support:** Native Bedrock touch-friendly Cumulus modal forms with font sanitization.
* **Strict Safe Teleportation:** Proactive checks prevent teleportation into lava, fire, suffocation blocks, or floating mid-air.
* **Social Home Sharing:** Invite friends to your home (`/home share <player> <home>`) with clickable in-chat **[ACCEPT]** and **[DECLINE]** buttons.
* **Enterprise Database Support:** Built on HikariCP connection pooling supporting SQLite, MySQL, MariaDB, PostgreSQL, and H2.
* **Rich Audio-Visual Feedback:** BossBar progress counters, ActionBars, title subtitles, particle trails, and sound effects.
