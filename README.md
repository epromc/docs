## 🔍 Ikhtisar Seluruh Plugin

### ⚡ [eTools](eTools/README.md)
**Modern Custom Tools & Utilities Engine**
* Modular custom tools: **Harvester Hoes**, **Sell Wands**, **Trench Pickaxes**, **Lightning Wands**, and **Sand Wands**.
* Persistent lifespan tracking via block breaks or real-time expiration.
* Direct Vault economy deposit with configurable sound effects and action bar alerts.
* [Explore eTools Documentation →](eTools/README.md)

### ⚙️ [eGens](eGens/README.md)
**Next-Gen Item Generator, Tycoon & Corruption Engine (`v1.0.1`)**
* **28 unified standalone generator configurations** (`generators/<name>_generator.yml`) with localized stats & drop tables.
* Physical world-drop loot dispatch with strict **Anti-Abuse Drop Locking** (zero placement/crafting exploits).
* Dynamic **Generator Corruption & Repair** and **Obstruction Protection** preventing AFK abuse.
* Dynamic tick rescheduling upon tier promotion, **SuperiorSkyblock2-style YAML GUI DSL**, sellwands, server events, live tick profiler, and automated backups.
* [Explore eGens Documentation →](eGens/README.md)

### 🛏️ [eHome](eHome/README.md)
**Bed-Themed Modern Home Management**
* Intuitive **16-color bed palette GUI** with pinned favorites and matrix pagination.
* Social home sharing (`/home share <player> <home>`) with clickable in-chat **[ACCEPT]** / **[DECLINE]** prompts.
* Multi-engine storage (SQLite, MySQL, MariaDB, PostgreSQL, H2) with HikariCP connection pooling.
* Proactive safe teleportation algorithms preventing lava, fire, or mid-air accidents.
* [Explore eHome Documentation →](eHome/README.md)
