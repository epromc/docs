## Plugin Overviews

### eTools

A modular, high-performance custom tools and utilities engine designed to elevate server gameplay:

* **Directional Mining** — 3x3 & 5x5 drills and shovels that adapt to the player's facing direction.
* **Tree Feller Axe** — BFS-based full tree felling with automatic leaf decay, up to 1,000 logs per swing.
* **Smart Farming Hoes** — AoE soil tilling (3x3 / 5x5) with instant crop harvesting and auto-replanting.
* **Infinite Utilities** — Infinite ender pearls, firework rockets, water/lava buckets, food items with anti-abuse auto-dissolve.
* **Lifespan System** — Online playtime, real-world countdown, or permanent tool lifespans.
* **Premium License** — Server-bound license key system with IP-limit protection and heartbeat validation.

[Read the eTools Documentation →](../etools)

---

### eGens

A next-generation resource generator and tycoon engine for Gens, Skyblock, and Prison servers:

* **28 Standalone Generators** — Unified 1-YAML configuration per generator (`wood`, `iron`, `diamond`, `wither`, `lightning`, etc.).
* **Anti-Abuse Drop Lock** — Generator drops cannot be placed, crafted, brewed, or smelted.
* **Corruption & Repair** — Periodic block wear requiring player maintenance to prevent AFK exploitation.
* **Economy & Sellwands** — Built-in `/sell`, chest sellwands with multipliers, and in-game generator shop.
* **Server-Wide Events** — Scheduled multiplier events with BossBar notifications and additive stacking.

[Read the eGens Documentation →](../egens)

---

### eHome

An intuitive, bed-themed home management plugin designed for modern survival networks:

* **Bed-Themed Matrix GUI** — Interactive chest menu featuring 16 color choices, pinned favorites, and pagination.
* **Safe Teleportation** — Proactive checks prevent teleporting into lava, fire, suffocation blocks, or empty air.
* **Social Home Sharing** — Invite friends with clickable in-chat **[ACCEPT]** and **[DECLINE]** prompts.
* **Multi-Database Support** — HikariCP pooling for SQLite, MySQL, MariaDB, PostgreSQL, and H2.

[Read the eHome Documentation →](../ehome)

---

### eNightVision

A lightweight, elegant night vision plugin with a premium Dynamic Island HUD:

* **One-Command Toggle** — Players toggle night vision instantly with `/nightvision` or `/nv`.
* **Dynamic Island HUD** — Animated action bar showing night vision state and cooldown timers.
* **Per-Player Persistence** — State is saved across server restarts and reconnections.
* **Permission-Based Access** — Granular permission nodes for toggle access and cooldown bypass.

[Read the eNightVision Documentation →](../enightvision)
