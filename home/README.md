## ⚡ Ikhtisar Plugin

### 🌾 1. [eTools](../etools)
Plugin alat custom modular berkinerja tinggi yang dirancang untuk memperkaya gameplay server:
* **Tool Khusus:** Harvester Hoe (panen otomatis), Sell Wand (jual isi peti instan), Trench Pickaxe (galian 3x3), Lightning Wand, dan Sand Wand.
* **Lifespan Tracking:** Durasi pemakaian berbasis waktu nyata atau jumlah blok yang dihancurkan dengan metadata PDC.
* **Integrasi Ekonomi:** Langsung terhubung dengan Vault dan didukung audio feedback.
* [**Lihat Panduan Lengkap eTools →**](../etools)

### 💎 2. [eGens](../egens)
Plugin generator sumber daya mutakhir untuk server Gens, Skyblock, dan Tycoon:
* **28 Generator Mandiri:** Arsitektur 1-file YAML per generator (`wood`, `iron`, `diamond`, `wither`, `lightning`, dll.).
* **Anti-Abuse Lock:** Item hasil generator tidak bisa ditaruh di tanah, di-craft, di-smelt, atau disalahgunakan.
* **Mekanik Korupsi & Perbaikan:** Generator aus secara berkala dan memerlukan perbaikan untuk mencegah AFK berlebihan.
* **Fitur Lengkap:** Matrix YAML GUI DSL, Sellwands dengan multiplier peti, auto-backup, dan tick profiler (`/egens perf`).
* [**Lihat Panduan Lengkap eGens →**](../egens)

### 🛏️ 3. [eHome](../ehome)
Sistem manajemen home modern bertema tempat tidur yang intuitif:
* **Bed-Themed Matrix GUI:** Antarmuka interaktif dengan 16 pilihan warna kasur dan pin favorit.
* **Safe Teleportation Proaktif:** Mencegah pemain terteleportasi ke dalam lava, api, blok padat, atau melayang di udara.
* **Berbagi Home (`/home share`):** Undang teman berkunjung ke home Anda dengan tombol klik [TERIMA] dan [TOLAK] di chat.
* [**Lihat Panduan Lengkap eHome →**](../ehome)

## 🖥️ Kompatibilitas Platform

| Komponen | Versi yang Didukung | Keterangan |
| :--- | :--- | :--- |
| **Java Runtime** | **Java 21+ & Java 25** | Menggunakan fitur virtual thread dan record modern. |
| **Server Software** | **Paper, Purpur, Folia** | Kompatibel penuh untuk versi **1.20.4 – 1.21.x** & **26.x**. |
| **Multi-Threading** | Native **Folia** | Isolasi thread region per chunk tanpa *main-thread blocking*. |
| **Ekonomi** | **Vault** (1.7+) | Transaksi ekonomi instan dan aman. |
