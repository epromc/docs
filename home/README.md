## ⚡ Plugin Overviews

### 🌾 1. [eTools](../etools)
A modular, high-performance custom tools and utilities engine designed to elevate server gameplay:
* **Custom Tools:** Harvester Hoe (auto-replant & harvest), Sell Wand (instant chest liquidation), Trench Pickaxe (3x3 mining), Lightning Wand, and Sand Wand.
* **Lifespan Tracking:** Block-break or real-time expiration tracking with PersistentDataContainer (PDC) metadata.
* **Economy Integration:** Seamless Vault deposits accompanied by configurable audio feedback and action bar counters.
* [**Read the Full eTools Documentation →**](../etools)

### 💎 2. [eGens](../egens)
A next-generation resource generator and tycoon engine tailored for Gens, Skyblock, and Prison servers:
* **28 Standalone Generators:** Unified 1-YAML configuration per generator (`wood`, `iron`, `diamond`, `wither`, `lightning`, etc.).
* **Anti-Abuse Drop Lock:** Generator drops cannot be placed as blocks, crafted, brewed, smelted, or abused in workstations.
* **Corruption & Repair:** Periodic block wear requiring player maintenance to curb runaway AFK exploitation.
* **Feature Packed:** SuperiorSkyblock2-style YAML GUI DSL, Sellwands with chest multipliers, automated live backups, and tick profiler (`/egens perf`).
* [**Read the Full eGens Documentation →**](../egens)

### 🛏️ 3. [eHome](../ehome)
An intuitive, bed-themed home management plugin designed for modern survival networks:
* **Bed-Themed Matrix GUI:** Interactive pattern menu featuring 16 color choices, pinned favorites, and pagination.
* **Proactive Safe Teleportation:** Advanced algorithms prevent teleporting into lava, fire, suffocation blocks, or empty air.
* **Social Home Sharing (`/home share`):** Invite friends to your homes with clickable in-chat **[ACCEPT]** and **[DECLINE]** buttons.
* [**Read the Full eHome Documentation →**](../ehome)
