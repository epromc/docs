# EproMC Plugin Documentation

EproMC builds Minecraft server plugins for Paper, Purpur, and Folia. All plugins are written in Java 21+ and designed to run without impacting server performance.

## eTools

Custom tools plugin with directional area mining (3x3 / 5x5), tree felling, AoE farming hoes, and infinite utility items such as ender pearls and firework rockets. Tools have a configurable lifespan that tracks active playtime, real-world time, or can be permanent. Sold via Discord with a server-bound license key.

[Read the eTools docs](../etools)

---

## eGens

Generator and tycoon plugin with 28 pre-built generator types, each configured in a single YAML file. Includes generator corruption and repair mechanics, physical world drops, built-in economy and sellwands, server-wide multiplier events, and native Folia support.

[Read the eGens docs](../egens)

---

## eHome

Home management plugin with a bed-themed GUI. Supports 16 bed colors per home slot, safe teleportation checks, home sharing between players, and multiple database backends (SQLite, MySQL, MariaDB, PostgreSQL, H2). Compatible with Geyser/Floodgate for Bedrock players.

[Read the eHome docs](../ehome)

---

## eNightVision

Simple night vision toggle via `/nv` or `/nightvision`. Shows status on the action bar with a cooldown timer. Player state persists across server restarts.

[Read the eNightVision docs](../enightvision)
